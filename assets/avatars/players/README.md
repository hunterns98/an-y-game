# Ảnh avatar người chơi

Đặt ảnh chân dung (nên là WebP vuông, tối thiểu 256 × 256) vào thư mục này.
Tên file cần đúng như sau:

`nhung.webp`, `thuy.webp`, `an.webp`, `thoan.webp`, `phuong.webp`, `anh.webp`, `giang.webp`, `hanh.webp`, `le.webp`, `mai-anh.webp`, `linh.webp`, `hang.webp`, `hoa.webp`, `trang.webp`, `truc.webp`, `lien.webp`.

Nếu một file chưa có hoặc không tải được, game tự dùng avatar minh hoạ mặc định; game vẫn chạy bình thường.
